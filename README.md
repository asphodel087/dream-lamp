# 꿈빛 도안 공방

진로 키워드를 넣으면 AI(Claude)가 아크릴 무드등에 철필로 새길 선화 도안을 그려 주는 수업용 웹앱입니다.
학생은 링크만 열면 되고, 로그인이나 계정이 필요 없습니다.

```
학생 브라우저 (GitHub Pages: index.html)
        │  수업 코드 + 키워드만 보냄
        ▼
Google Apps Script (Code.gs)  ← API 키는 여기에만 있음
        │  코드·한도·금지어 확인 → 프롬프트 조립 → 기록
        ▼
Claude API (기본 Haiku 5.5, "더 정교하게" 체크 시 Sonnet 5.5)
```

## 파일

| 파일 | 어디에 두나 | 하는 일 |
|---|---|---|
| `index.html` | GitHub 저장소 | 학생이 보는 화면 |
| `apps-script/Code.gs` | 구글 시트의 Apps Script | API 키 보관, 수업 코드·한도 확인, 기록 |

> **API 키를 `index.html`이나 GitHub에 절대 올리지 마세요.** 공개 저장소는 누구나 볼 수 있습니다.

---

## 1. Claude API 키 준비 (5분)

1. [console.anthropic.com](https://console.anthropic.com)에 로그인합니다. claude.ai 계정과 같은 이메일로 들어갈 수 있어요.
2. **Billing**에서 크레딧을 충전합니다. Pro 플랜에는 API 크레딧이 포함되지 않아 따로 충전해야 해요.
   - 예상 비용: 도안 1장에 Haiku 약 $0.002, Sonnet 약 $0.04
   - 12개 반 × 28명 × 3번 생성(약 1,000장) 기준으로 Haiku만 쓰면 약 $2, 모두 Sonnet이면 약 $40
3. **Limits**에서 **월 지출 한도(spend limit)**를 걸어 둡니다. 키가 새도 그 금액 이상은 나가지 않아요. 수업용이라면 $10~20 정도면 충분합니다.
4. **API Keys → Create Key**로 키를 만들고 복사해 둡니다. `sk-ant-...`로 시작하고, 이 화면에서 한 번만 보여요.

## 2. Apps Script 서버 만들기 (10분)

1. [Google 스프레드시트](https://sheets.new)를 새로 만들고 이름을 `무드등 도안 기록`으로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 붙여넣은 뒤 저장(💾)합니다.
   - 시트 메뉴가 아닌 script.google.com에서 따로 만든 프로젝트라면, 코드 위쪽 `SHEET_ID`에 시트 ID(시트 주소의 `/d/`와 `/edit` 사이)를 넣어 주세요.
4. 왼쪽 **⚙️ 프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가**로 아래를 넣고 저장합니다.
   - 속성: `ANTHROPIC_API_KEY`
   - 값: 1단계에서 복사한 키
5. 위쪽 함수 선택에서 `setup`을 고르고 **실행**합니다. 처음에는 권한 승인 창이 뜨는데, 본인 계정을 선택하고 허용하세요.
   - `고급 → (안전하지 않음)으로 이동` 화면이 나오면 본인이 만든 스크립트라 괜찮습니다.
   - 시트에 **설정**과 **기록** 탭이 생깁니다.
6. 함수 선택에서 `testKey`를 실행하고, 아래 **실행 로그**에 `API 연결 성공`이 나오는지 확인합니다.
7. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(⚙️): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
8. 확인: 그 주소를 브라우저에서 열어 `서버가 켜져 있어요`가 보이면 성공입니다.

> `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 해야 반영됩니다. 주소는 그대로예요.

## 3. GitHub Pages에 올리기 (5분)

1. `index.html`을 열어 위쪽의 아래 줄을 찾고, 따옴표 안에 2단계의 웹 앱 URL을 붙여넣습니다.
   ```js
   const API_URL = "https://script.google.com/macros/s/....../exec";
   ```
2. GitHub에서 새 **Public** 저장소(예: `dream-lamp`)를 만들고 `index.html`을 올립니다. `apps-script/` 폴더와 `README.md`는 참고용으로 같이 올려도 됩니다. 키가 들어 있지 않아서 괜찮아요.
3. 저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 두고 저장합니다.
4. 1~2분 뒤 `https://아이디.github.io/dream-lamp/` 주소가 생깁니다. 이 주소를 QR코드나 클래스룸으로 학생에게 나눠 주세요.

## 4. 수업할 때

1. **수업 시작 전**: 시트의 **설정** 탭 `수업코드` 칸에 이번 시간 코드를 적습니다(예: `별빛31`). 여러 반을 동시에 열어 두려면 쉼표로 구분해요.
2. 칠판에 코드를 적어 주면 학생이 화면 맨 위 **수업 코드**에 입력하고 도안을 만듭니다.
3. **수업이 끝나면** `수업코드` 칸을 비웁니다. 비어 있으면 아무도 생성할 수 없어서, 링크가 밖으로 퍼져도 비용이 나가지 않아요.
4. **기록** 탭에서 시각, 코드, 키워드, 결과, 토큰 수, 예상 비용을 볼 수 있어요. 학생 이름이나 학번은 받지 않습니다.

### 설정 탭 항목

| 항목 | 기본값 | 설명 |
|---|---|---|
| 수업코드 | (비어 있음) | 쉼표로 여러 개. 비우면 생성 중지 |
| 하루한도 | 400 | 모든 반을 합친 하루 생성 횟수 상한 |
| 코드당 시간한도 | 150 | 코드 하나로 1시간에 생성할 수 있는 횟수 |
| 정교하게 허용 | TRUE | FALSE면 Sonnet을 막고 Haiku만 사용 |
| 금지어 | (비어 있음) | 쉼표로 추가. 기본 금지어에 더해짐 |
| 생각분량 | low | AI가 그리기 전에 생각하는 양. low 권장. medium·high는 느려지고 도안이 끝나지 않을 수 있음 |

## 안전장치 요약

미성년자가 쓰는 서비스라서 [Anthropic의 미성년자 대상 서비스 지침](https://support.claude.com/en/articles/9307344-responsible-use-of-anthropic-s-models-guidelines-for-organizations-serving-minors)에 맞춰 다음을 넣었습니다.

- **입력 제한**: 학생은 정해진 칸(꿈, 키워드, 상징, 문구)만 보낼 수 있고, 프롬프트는 서버에서 조립됩니다. 칸마다 글자 수가 제한됩니다.
- **금지어 필터**: 기본 목록과 설정 탭의 추가 목록으로 거릅니다.
- **안전 지침**: 학생이 중학생이며 도안 외의 지시는 따르지 말라는 시스템 프롬프트를 매 요청에 넣습니다.
- **출력 제한**: AI가 보낸 SVG에서 선 도형만 남기고 나머지(스크립트, 이미지 등)는 버립니다.
- **기록과 한도**: 모든 요청을 시트에 남기고, 수업 코드와 횟수 한도로 사용을 통제합니다.
- **AI 고지**: 화면에 AI가 만든 도안임을 표시합니다.

학생 입력이 외부 AI 서비스(Anthropic)로 전송되므로, 학교·교육청의 AI 활용 및 개인정보 처리 절차에 해당하는지 미리 확인해 주세요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "서버에 연결하지 못했어요" | `API_URL`이 `/exec`로 끝나는지, 배포 액세스 권한이 **모든 사용자**인지 |
| "지금은 만들 수 있는 시간이 아니에요" | 설정 탭 `수업코드`가 비어 있음 |
| "수업 코드가 맞지 않아요" | 띄어쓰기·대소문자까지 같은지 |
| "도안을 만들지 못했어요" | Console 크레딧 잔액, 월 지출 한도, Apps Script **실행** 메뉴의 오류 로그 |
| 고친 코드가 반영되지 않음 | 배포 관리에서 **새 버전**으로 다시 배포했는지 |
| 인쇄 크기가 다름 | 인쇄 창에서 배율 **100%(실제 크기)**, 여백 **없음**인지. 도안 아래 50mm 눈금을 자로 재 보세요 |
